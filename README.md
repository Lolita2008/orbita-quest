# Орбита — миссия «Маяк»

Интерактивный образовательный квест на русском языке: 10 решений, 5 этапов, подсказки и итоговый разбор.

## Открыть на компьютере

Скачайте все файлы в одну папку и откройте index.html в браузере двойным щелчком. Сервер, установка программ и вход в ChatGPT не нужны. Игровая часть работает без интернета; внешние ссылки на материалы NASA требуют подключения.

## Загрузить в GitHub

1. Создайте репозиторий или откройте существующий.
2. Загрузите содержимое этой папки в корень репозитория, сохранив имена файлов.
3. Чтобы сайт открывался по ссылке, в Settings → Pages выберите Deploy from a branch, ветку main (или свою основную ветку), папку / (root) и сохраните.
4. После публикации GitHub покажет адрес сайта в разделе Pages.

## Редактировать

- mission.js — вопросы, варианты, объяснения и сюжет.
- app.js — логика прохождения и подсчёт баллов.
- style.css и mission.css — оформление.
- index.html — структура страницы.

Сборка и зависимости отсутствуют. Ответы хранятся только в памяти вкладки и сбрасываются при обновлении. Данные участников никуда не отправляются. На обычном статическом хостинге файл index.html служит главной страницей.
